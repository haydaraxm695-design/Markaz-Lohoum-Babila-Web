# موقع مركز اللحوم ببيلا
واجهة منيو عربية RTL، موبايل أولاً، مستوحاة من تجربة مواقع المنيو الحديثة وليست نسخة من موقع آخر.

## الملفات
- `index.html` المنيو للزبون
- `admin.html` لوحة تجريبية لإدارة المنتجات على نفس الجهاز
- `styles.css` التصميم
- `app.js` السلة والواتساب والتصنيفات
- `assets/logo.jpg` شعار مركز اللحوم ببيلا المرفوع سابقاً

## مهم قبل النشر النهائي
نسخة الإدارة الحالية تحفظ البيانات في LocalStorage على نفس الجهاز فقط. لعمل لوحة إدارة حقيقية يتغير منها السعر والصورة ويظهر التعديل فوراً لكل الزبائن، يجب ربط الموقع بـ Firebase Web App وFirestore مع صلاحيات الإدارة. لا تضع كلمة مرور أو مفتاح سري داخل ملفات الموقع.
